# iTE

iTE is an AI coding agent for your terminal.

This extension runs iTE in a dedicated VS Code terminal beside your current editor.

If iTE is not installed, the extension asks before running the official installer from `ite.kiishi.space`.

Open iTE from the status bar or Command Palette.

## Docs

Learn more at [ite.kiishi.space/docs](https://ite.kiishi.space/docs).

## Privacy

The extension does not collect telemetry, bundle the runtime, or proxy iTE. Installation runs visibly in the terminal.
