Open iTE from:

- the `iTE` status-bar item
- the Command Palette with `iTE: Open iTE`

The extension launches the iTE runtime for the workspace you already have open, then displays Reup in a dedicated VS Code terminal.

By default, the extension prefers its managed runtime. If you already installed iTE with `pipx` or `uv`, that system runtime can be used as a fallback.
