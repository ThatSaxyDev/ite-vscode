Open iTE from:

- the `iTE` status-bar item
- the Command Palette with `iTE: Open iTE in VS Code`

The extension launches the iTE runtime for the workspace you already have open, then displays the Textual UI inside a VS Code webview.

By default, the extension prefers its managed runtime. If you already installed iTE with `pipx` or `uv`, that system runtime can be used as a fallback.
